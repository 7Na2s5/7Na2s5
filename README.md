## Pratique technique

- **Développement :** Python, C, Java, PHP et SQL dans des projets universitaires.
- **Réseau et systèmes :** sockets TCP/UDP, processus, signaux et communications interprocessus.
- **Données et outils :** SQLite, Git, NumPy, Matplotlib, Flask ; projets web avec Symfony.
- **Démarche sécurité :** comprendre les limites d'un mécanisme, isoler les expériences, utiliser des données synthétiques et documenter les résultats.
